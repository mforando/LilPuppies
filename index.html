LilPuppies

Inspired by ProPublica’s WeePeople font (github.com/propublica/weepeople).

A font of dog silhouettes for unit charts, following WeePeople’s idea of one figure per letter. Each of the 52 letters is a different breed, traced from a photo in the Dog CEO API. Where a breed’s name allows it, the letter is its initial: B is a basset hound.

Use it

<link rel="stylesheet" href="lilpuppies.css">
<span class="lilpuppies">BbDdGg</span>

The CSS embeds the font, so it is the only file you need. Or load lilpuppies.woff2 / lilpuppies.woff / lilpuppies.ttf with your own @font-face. Space is a gap the width of a dog. Only A–Z and a–z have dogs, the same characters as WeePeople.
