WeeDogs

A font of dog silhouettes for unit charts, in the spirit of ProPublica’s WeePeople. Each of the 52 letters is a different breed, traced from a photo in the Dog CEO API. Where a breed’s name allows it, the letter is its initial: B is a basset hound.

ABCDEFGHIJKL

In a chart

One dog per unit; color some of them. The letters cycle through every breed.

Use it

<link rel="stylesheet" href="weedogs.css">
<span class="weedogs">BbDdGg</span>

The CSS embeds the font, so it is the only file you need. Or load weedogs.woff2 / weedogs.woff / weedogs.ttf with your own @font-face. Space is a gap the width of a dog. Only A–Z and a–z have dogs, the same characters as WeePeople.

Silhouettes traced from photos in the Stanford Dogs Dataset (Khosla et al. 2011, from ImageNet), served by the Dog CEO API; licensed for non-commercial research and education, so WeeDogs is for non-commercial use too. The source photo for every letter is listed in weedogs.json and README.md. WeeDogs is not affiliated with ProPublica and uses none of WeePeople’s shapes.
